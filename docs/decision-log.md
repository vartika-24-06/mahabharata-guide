- Switched the build-time embeddings provider from Gemini (`gemini-embedding-2`) to OpenAI (`text-embedding-3-small`). Reason: Gemini's free tier caps at 1,000 embedding requests/day (not per-minute as first assumed) - would take ~6 days to embed the full 5,578-passage corpus. Enabling billing to lift that cap required a disproportionate minimum prepaid top-up (~3,000 INR) versus the real cost. OpenAI's text-embedding-3-small costs ~$0.07 for the whole corpus (~3.3M tokens) with a proportional ~$5 minimum top-up, and supports truncating to the same 768 dimensions via its `dimensions` parameter, so the Supabase schema didn't need to change. Any rows already pushed with Gemini embeddings had to be truncated first - different embedding models are not comparable in the same vector search.

- Task 15 (story endpoint) defined as `POST /api/story`, mirroring `/api/ask`'s header/error contract (Task 13). The source text has no marked story-arc boundaries, so "a story" is modeled as a naive, honestly-documented simplification: a contiguous run of a subject's catalogue sections, chunked into fixed groups of 3 ("episodes") in canonical book/section order. "Tell me more" (Req 7.2) continues to the next episode for the same subject; "I already know this one" (Req 7.3) jumps to a different episode for the same subject, preferring one not in the browser's Shown Stories list; when there's no other episode, says so instead of repeating (Req 7.4). A `story_id` (`"<subject>#<episode_index>"`) is how the browser's Shown Stories list identifies an already-seen episode - sent back on each request. Character/parva/surprise picks fetch their known sections directly from Supabase (no search needed, since the catalogue already says which sections apply); typed requests go through the same `search.hybrid_search()` as Q&A, since there's no catalogue entry to look up. "No good story" is judged the same way as Q&A's "no good answer" - zero citations survive `answer.build_citations()`, reused as-is rather than writing a parallel citation builder. 15 new tests, all mocked.
